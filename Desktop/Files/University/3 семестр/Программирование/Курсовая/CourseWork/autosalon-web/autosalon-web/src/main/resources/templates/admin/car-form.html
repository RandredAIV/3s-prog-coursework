Информация о добавлении

  • После добавления болид появится в каталоге как новая плитка
  • Для добавления фотографии поместите файл с названием ID.jpg в папку /images/cars/
  • ID болида будет присвоен автоматически после сохранения
  • Обязательные поля отмечены звёздочкой (*)
  • Все числовые поля имеют ограничения для реалистичных значений F1

Информация о редактировании

  • Изменения сохранятся сразу после нажатия кнопки "Сохранить изменения"
  • Для обновления фотографии замените файл с названием ID.jpg в папке /images/cars/
  • Обязательные поля отмечены звёздочкой (*)
  • Все числовые поля имеют ограничения для реалистичных значений F1
