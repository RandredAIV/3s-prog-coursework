AVRAMCHUK BOLID MOTORSPORT

Коллекция чемпионских и культовых болидов 1980–2024 годов.
Этот проект — учебный автосалон, посвящённый технике Формулы-1. Здесь собраны болиды, которые выигрывали титулы конструкторов, ломали рекорды и оставляли след в истории чемпионата. Для каждого болида оформлена карточка с сезоном, командой, результатами и оценочной стоимостью коллекционного экземпляра.

Каталог можно фильтровать по цене, наличию, производителю и сезону, а также сортировать по имени, цене и году. В будущем появятся личный кабинет, корзина и полноценная система заказов.
